# 🥊 GloveUp! 한국어 패치

**GloveUp! 게임 속 글자를 한국어로 바꿔 주는 무료 한글패치**예요! 🎉

- **비공식 팬 제작 패치**예요. 게임 개발사가 만든 공식 번역은 아니에요.
- 개발자에게 팬 번역 제작 및 무료 배포에 대한 허락을 받았어요.
- **게임 자체는 들어 있지 않아요.** Steam에서 GloveUp! 게임을 먼저 설치해야 해요.

## ✅ 설치하기 전에 꼭 확인해 주세요

이 패치는 아래 게임 버전에서만 사용할 수 있어요.

| 항목 | 지원 버전 |
| --- | --- |
| 게임 | **GloveUp!** (Windows / Steam) |
| 게임 버전 | **0.3.0** |
| Steam 빌드 번호 | **26487554** |
| 한글패치 버전 | **0.3.0** |

**게임 버전 숫자가 같아도 Steam 빌드 번호가 다르면 사용할 수 없어요.** 지원하지 않는 버전이면 설치 프로그램이 멈추도록 만들어져 있어요.

이전 Steam 빌드 **26424745**용 패치는 [기존 v0.3.0 릴리스](https://github.com/dbsgur157/GloveUp-Korean-Patch/releases/tag/v0.3.0)에서 받을 수 있어요.

설정·메인 메뉴·캐릭터 편집·능력 설명, 컨트롤러 배치, 스탠스·기술 안내, 업데이트 소식, 일어나기 미니게임 및 조작 설명을 새 원본에 맞게 갱신했어요.

## 📥 한글패치 설치 방법 (딱 5단계!)

1. Steam에서 **GloveUp! 게임 설치와 업데이트를 끝내 주세요.**
2. 게임이 켜져 있다면 **완전히 꺼 주세요.**
3. [Steam Build 26487554용 한글패치 다운로드](https://github.com/dbsgur157/GloveUp-Korean-Patch/releases/tag/v0.3.0-build26487554)로 가서 **Assets(파일)**의 `GloveUp_KoreanPatch_0.3.0_Build26487554.zip`을 다운로드하세요.
4. 다운로드한 ZIP 파일을 **마우스 오른쪽 클릭 → 모두 압축 풀기**로 풀어 주세요. 새로 생긴 폴더를 열고 **`Install.cmd`를 두 번 클릭**하세요.
5. 설치 프로그램에서 **설치가 끝났다는 안내**가 나오면, 평소처럼 **Steam에서 게임을 실행**하세요. 이제 한국어로 즐기면 돼요! 🎮

> 💡 **중요!** ZIP 압축파일 안에서 `Install.cmd`를 바로 실행하지 마세요. **반드시 먼저 압축을 풀어야 해요.** 게임 폴더는 설치 프로그램이 자동으로 찾아요.

## 🧹 한글패치를 지우고 원래대로 돌아가기

**이 패치는 게임 실행 파일(`GloveUp.exe`)의 일부도 바꿔요.** 따라서 그냥 ZIP만 지운다고 원래대로 돌아가지 않아요.

1. **게임을 종료**하세요.
2. Steam 라이브러리에서 **GloveUp!을 마우스 오른쪽 클릭 → 관리 → 로컬 파일 탐색**을 누르세요. (메뉴 이름이 다르면 **속성 → 설치된 파일 → 찾아보기**로 열면 돼요.)
3. 열린 게임 폴더 안에서 **`GloveUp\Content\Paks`** 폴더로 들어가 다음 **4개 파일만** 지워 주세요.
   - `GloveUp_Korean_P.pak`
   - `GloveUp_KoreanAssets_P.pak`
   - `GloveUp_KoreanAssets_P.utoc`
   - `GloveUp_KoreanAssets_P.ucas`
4. 다시 Steam에서 **GloveUp! 마우스 오른쪽 클릭 → 속성 → 설치된 파일 → 게임 파일 무결성 검사**를 누르세요.
5. 검사가 끝나면 Steam이 게임의 원본 파일을 복구해 줘요.

> ⚠️ **순서가 중요해요!** 위의 패치 파일 4개를 먼저 지우고, 그다음에 게임 파일 무결성 검사를 해 주세요. 무결성 검사만 하면 추가된 패치 파일이 남을 수 있어요.

## ❓ 설치가 안 되거나 업데이트가 됐다면?

- **지원하지 않는 버전이라고 나와요.** → 게임이 업데이트돼서 패치와 버전이 달라졌을 수 있어요. **억지로 설치하지 말고**, 새 버전의 한글패치를 기다려 주세요.
- **게임 설치 폴더를 못 찾는다고 나와요.** → 다운로드한 ZIP에 들어 있는 **`사용안내.txt`**를 열면 게임 폴더를 직접 지정하는 방법이 적혀 있어요.
- **게임 업데이트 후 문제가 생겨요.** → 위의 **「한글패치를 지우고 원래대로 돌아가기」**를 따라 해 주세요.

## 📌 참고해 주세요

- **무료**로 배포하는 팬 번역입니다. GloveUp! 원본 게임 파일 전체는 포함하지 않아요.
- Steam 게임 업데이트 후에는 패치가 작동하지 않을 수 있어요.
- 설치기는 **Steam 빌드와 원본 게임 파일 6개의 해시를 확인한 뒤** 수정합니다. 강제 설치는 지원하지 않아요.
- ZIP 무결성과 포함 리소스 해시는 확인했지만, **실제 게임 실행 및 플레이 검수는 수행하지 않았어요.**
- ZIP 안의 `사용안내.txt`에는 더 자세한 설명이 있어요.
